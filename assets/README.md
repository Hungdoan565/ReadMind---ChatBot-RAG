# Assets

This folder contains visual assets for the README.

## Required Assets

### demo.gif
A 15-30 second GIF demonstrating the main workflow:
1. Upload a document
2. Ask a question
3. Get an AI response with source citations
4. (Optional) Show room switching / theme toggle

### Recommended specs:
- **Resolution**: 1200x800px (wide format)
- **Duration**: 15-30 seconds
- **File size**: < 5MB (optimize with ezgif.com)
- **Content**: Use real data, not Lorem Ipsum

## How to Record

### Option 1: LICEcap (Windows/Mac)
```bash
# Download from https://www.cockos.com/licecap/
# Record at 10-15 FPS for smaller file size
```

### Option 2: ScreenToGif (Windows)
```bash
# Download from https://www.screentogif.com/
# Export with optimization enabled
```

### Option 3: Kap (Mac)
```bash
brew install --cask kap
```
